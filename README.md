## Project Overview

LEFT is a fictional sneaker retail website created as a web development project. The website allows users to browse sneakers, learn more about the brand, make enquiries, and access contact information.

## Website Goals & Adjectives

The main goal of LEFT is to create a bold, user-friendly sneaker retail website that presents products clearly and provides users with an easy way to browse products and access relevant information.

The website aims to have a modern, bold, clean, and visually engaging design.

## Key Features and Functionality

* Homepage with navigation and hero section
* Shop page with twelve sneaker products
* Search and brand filter structure
* About page
* Enquiry form
* Contact page
* Google Maps location
* Footer
* LEFT logo
* Semantic HTML structure
* Responsive layouts for desktop, tablet, and mobile screen sizes
* Hover and focus states
* CSS Grid and Flexbox layouts
